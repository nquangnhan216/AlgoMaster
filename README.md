# AlgoMaster
A practical learning taxonomy for algorithms, organized into seven levels: recognize, trace, implement, analyze, choose, modify, and transfer. It helps turn “I kind of know this algorithm” into clear, testable stages of mastery.


# How I came to make this
When I started learning algorithms, I found them confusing and difficult to retain. After a while, I realized that breaking an algorithm into smaller “parts” made it much easier to learn. But that raised another question: what exactly should those “parts” be? After spending some time discussing the problem with others and refining the idea, I came up with a set of achievement levels for learning algorithms, as outlined in this document. However, I am still quite a newbie, so I'm open to changes/recommendations.

Tip: use this as a benchmark, send it to an AI for per-level exercises (that's what I did)
